# 📱 FIMAP Mobile - Aplicativo Android

> **Fimap / Auxiliar Financeiro Mobile**
>
>Repositório do aplicativo mobile do **FIMAP** (Auxiliar Financeiro), desenvolvido como parte do Trabalho de Conclusão de Curso (TCC) do técnico em Desenvolvimento de Sistemas do Senai de Jandira.

---
## 📋 Sobre o Projeto
O Fimap é uma aplicação voltada ao mercado financeiro para auxiliar usuários a gerenciarem seu dinheiro e entenderem questões financeiras de maneira orgânica. Esta versão mobile foi desenvolvida nativamente para Android utilizando Kotlin e Jetpack Compose.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** [Kotlin](https://kotlinlang.org/)
* **Interface Gráfica:** Jetpack Compose
* **Arquitetura e Componentes:** Android Studio, Gradle
